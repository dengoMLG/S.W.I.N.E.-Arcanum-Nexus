# Мод-пак Arcanum S.W.I.N.E.

Лаунчер Arcanum ставит этот пак целиком кнопкой «Установить все моды». У всех игроков одна и та же сборка; проверить это можно по коду сборки на странице игры.

## Как устроен мод

Мод — это папка `mods/<id>/` с файлами по тем же путям, что и в игре:

```
mods/my-mod/
  gamedata/base/units.ini.arcpatch        ← правка units.ini (сливается с другими модами)
  gamedata/base/missions/ny_01.scene      ← файл целиком (заменяет оригинал)
```

- **Файл целиком** заменяет файл игры. Если два мода кладут один и тот же файл, побеждает тот, что ниже в `pack.json`.
- **`.arcpatch`** — правка INI поверх того, что уже собрано (оригинал из `base.pak` или результат модов выше по списку):

```ini
[Diszno normal tank]
MaxHP = 95        ; заменить значение
-ShotSound        ; удалить ключ
[New section]     ; секции нет — добавится в конец
Model = units\x
```

Секции и ключи не чувствительны к регистру. Остальной файл (комментарии, отступы, CRLF) не меняется.

## Выпуск новой версии пака

1. Добавить или изменить мод в `mods/`, вписать его в `pack.json` (`"source": "mods/<id>"`).
2. Поднять `"version"` в `pack.json`. Иначе у игроков, у которых пак уже стоит, обновление не установится.
3. `node tools/build-modpack.js`, на выходе `modpack/out/modpack.json` и `modpack/out/mods/*.zip`.
4. Выложить на CDN:
   - `out/mods/*.zip` → `/srv/arcanum/dist/launcher/games/swine/mods/`
   - `out/modpack.json` → `/srv/arcanum/dist/launcher/games/swine/modpack.json` (последним, после zip).

Лаунчер подхватит новую версию при открытии страницы и поставит её перед «Играть».

Если `modpack.json` на CDN нет или он битый, лаунчер берёт последнюю скачанную копию, а без неё — вшитый пак (только Full ReBalance).
