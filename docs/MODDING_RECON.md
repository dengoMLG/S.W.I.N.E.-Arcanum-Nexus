## Что можно модить

**Уровень 1 — только данные (без кода, работает уже сейчас):**
- `units.ini` — параметры всех юнитов: HP, броня, урон, дальность, скорость, цена, топливо, патроны, перезарядка, тип снаряда, XP за уровни, множители рас.
- `objects.ini`, `effects.ini`, `decals.ini`, `robbanastipusok.ini` (типы взрывов), `units_color.ini`, `cameras.ini`.
- `missions.ini` + `missions/*.scene` — кампания, доступные юниты (`UnitMask`), SP.
- Мультиплеерные карты `.scene` через официальный `editor.exe` (хост сам раздаёт их игрокам).
- Готовые армии (`armies/*.army`).
- Текстуры `.dxt`/`.png`, звуки, музыка, тексты локализаций.

**Уровень 2 — код (через DLL с PDB):**
- Добавить путь поиска (`SFileSystem::AddSearchPath`): моды грузятся из `mods\...`, а файлы игры не трогаются вообще.
- Дописать хэш мод-пака к сетевой версии (`SVersion::GetNetworkString`): друг с другим набором модов не сможет зайти (игра скажет «Version mismatch»), вместо кика посреди матча.
- Новые правила: условия победы, таймеры, лимиты, авиаудары (`SGameWorld::AirStrike`), зарплата/SP, чат-команды.
- Оверлей поверх `d3d9` (показывать версию пака, пинг).

## Дальнейшие шаги

1. **Мод-пак в лаунчере.** Сейчас `SwineGame.cs` умеет ставить один мод. Нужно сделать манифест на CDN со списком модов и их sha256, кнопки «Установить все моды» / «Удалить моды», журнал и бэкапы уже есть. Показывать короткий хэш пака, чтобы сверяться с друзьями.
2. **Кнопки онлайна:** «Хостить» (`+host`) и «Подключиться» (`+connect IP`), игра запускается через Steam с этими параметрами.
3. **Нативный загрузчик** (`winmm.dll`, x86) с хэшем пака в версии и папкой `mods\` вместо замены файлов.
4. Сами моды.
