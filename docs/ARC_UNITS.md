# Arcanum Units: новые юниты и баланс

Исходник — `tools/arc-units.js` (все цифры там). Сборка тестовой версии:

```
node tools/arc-units.js mods-test/arcunits                  # units.ini, units_text.ini, classes.json, balance.json
node tools/make-test-tank.js <out> --race pig               # модель, иконки, ролик магазина (d_arctank)
node tools/make-test-tank.js <out> --race rabbit            # то же для кроликов (ny_arctank)
node tools/build-all-units.js                                    # все 10 новых моделей + иконки + ролики .anif + аудит
tools/re/bin-patchgen/patchgen.exe <orig exe> <out> --classes mods-test/arcunits/classes.json
node tools/wiki-arc-units.js mods-test/arcunits/balance.json   # страницы вики из balance.json
```

## Механика, найденная в exe

Это нужно для баланса; адреса указаны в `re/*.asm`.

- **Урон** (`SUnit::TakeDamage`). Урон попадания = урон − броня стороны.
  - Сторона выбирается по направлению попадания: лоб (±45°), корма или борт. Броня борта = (лоб + корма) / 2.
  - Навесные снаряды бьют в `TopArmor`.
  - Если урон ≤ 0, попадание ничего не снимает.
  - У окопанного танка (`SpecialType 0`) к броне прибавляется `ExtraArmor`.
- **`Damage` читается как целое число** (`GetInt`); дробная часть отбрасывается.
- **Уровни.** Рядовой: урон +0 / броня +0. Ветеран: +0.4 / +0.4, HP ×1.2. Элита: +1.0 / +1.0, HP ×1.5. Бонусы одинаковы для всех юнитов и зашиты в exe.
- **Опыт.**
  - Пороги задают `Level2XP` и `Level3XP`. По умолчанию это 4·HP+20 и 10·HP+20.
  - Опыт начисляется за нанесённый урон (`SGameWorld::IncreaseUnitXP`). Юниты без оружия не растут.
- **Улучшения.**
  - `UpgradeMask` — набор битов: топливо 1, боезапас 2, обзор 4, миноискатель 8, броня 16, ремкомплект 32, турбо 64, пиво 128, морковный напиток 256.
  - Эффекты: обзор +3, броня +1 ко всем сторонам, боезапас +25 %, топливо +20, скорость +20 %, перезарядка −10 %.
  - Цены задаются в секциях `[Upgrade …]` и общие для всех юнитов. На юнит ставится не больше 3 улучшений.
- **Без эффекта.**
  - `AmmoValue` игра не читает.
  - `ExplodeType` выбирает только обломки (0–3).
  - `Resource = 1` значит «прицеп можно захватить», `Resource = 2` — флаг, который приносит очки.
  - Ездит юнит или нет, решает `MoveType` (0 — не ездит).
- **Магазин.**
  - «Скорость» = `MoveSpeed`·50.
  - «Расход топлива» = 100·`MaxFuel`/`Consume`: меньше `Consume` — прожорливее.
  - «Бронь по бокам» = (лоб + корма) / 2.

## Правки старых юнитов

Источник жалоб — обсуждения в Steam и гайды сообщества:
- кроличий истребитель танков с самонаводящимися ракетами быстрее свиных танков и бьёт дальше них;
- артиллерия — сильнейший юнит;
- мортиры почти бесполезны.

Каждая правка с причиной записана в `VANILLA` в `tools/arc-units.js` и попадает в вики (страница «Правки старых юнитов»).

## Чего пока нет (нужен код, а не ini)

- **Проверка моделей.** Правила и инструменты — в `docs/MODEL_RULES.md`. Перед установкой: `node tools/swine-4d-orient.js check` для каждой `.4d`.
- **Модели.** Все 10 новых юнитов (5 свиней: `d_hryakgrill`, `d_svinczar`, `d_bombohryak`, `d_osadnykaban`, `d_gryazemet`; 5 кроликов: `ny_zayacprizrak`, `ny_morkovsmerch`, `ny_krotoboy`, `ny_pitstop`, `ny_ushastik`) имеют свои 3D-модели в `tools/models/*.js` на общей библиотеке `tools/lib/swine-model-kit.js` и подключены через поле `model` в `tools/arc-units.js`. 5 гусеничных используют `MoveType 1` (`Chain R/L 001`), 5 колёсных — `MoveType 2` (`Wheel R/L 1 N001` спереди для руления, `Wheel R/L 0 N002` сзади). На временной модели `d_arctank` / `ny_arctank` остаётся только «Чародей».
- **Иконка и ролик магазина** собираются из модели (`buildUnitPackage`): серый фон 124,122,124, тень, танк смотрит влево (`SHOP_YAW`), ролик — 200 кадров полного оборота 496×368.
- **Гряземёт.** Не замедляет врагов: бурое облако — только эффект.
- **Морковный Смерч.** Залп как у обычной ракетной установки: `ReshotTime` и спецрежим `SpecialType 6`. Своего числа ракет в залпе нет.
- **Пит-Стоп.** Самоходный `SpecialType 8` без `Resource` в игре не встречается. Работает ли ремонт, надо проверить в бою.
- **Бомбохряк.** Взрывается только при гибели: кнопки подрыва нет.
- **Покупка во время матча.** Новых юнитов нет в быстром магазине.

## Баланс: симуляция и цены (тестовая сборка 2)

- `node tools/balance-sim.js [units.ini] [--level 0|1|2] [--budget 4000] [--solve out.json]`. Это бои один на один и группами на равные деньги по формулам игры, с учётом:
  - брони сторон;
  - бонусов уровня;
  - сближения;
  - обзора: без наводчика огонь не дальше обзора + 1;
  - разброса навесного огня;
  - залпов.
- Цены: всё, что продаётся, ×1.6 (`PRICE_SCALE` в `tools/arc-units.js`). Боевые юниты берут цены из `modpack/balance/prices.json`: подбор симулятором, поправка применена наполовину, обычный танк = 650. Свин-Царь по ТЗ стоит 1800 (45 % от 4000 SP). Варианты стартового бюджета в лобби: 4000/6500/9000/16500/24000.
- Чего модель не знает: рельеф, укрытия, туман войны, микроконтроль. Поэтому юниты, которые бьют с дистанции и уходят от ответа (Заяц-Призрак), в ней выглядят сильнее, чем в игре, а штурмовики ближнего боя — слабее.

## Песочница

`swineHD.exe missions/<карта>.scene` → `SCampaign::InitScenarioMode`: магазин с маской сетевой игры (все новые юниты), 100 000 SP, затем карта кампании с врагами. Ярлыки: `modpack/sandbox/sandbox-rabbits.cmd` (d_04) и `sandbox-pigs.cmd` (ny_08).
