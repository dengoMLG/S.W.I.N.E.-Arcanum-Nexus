# S.W.I.N.E. HD — Arcanum Nexus mods

Моды для S.W.I.N.E. HD Remaster (v1.7.1846) для сетевой игры с друзьями. Раздаются через лаунчер Arcanum.

- `docs/` — разбор игры, патча exe, механик и правил моделей.
- `tools/` — сборка мода Arcanum Units (данные юнитов, модели, эффекты, сетевые карты, патч exe, мод-пак, вики).
- `modpack/` — исходники мод-пака и вики.

Файлы игры в репозиторий не входят: для сборки нужна своя установленная копия игры (см. `CLAUDE.md`).
